# Results

## Logging into the server

After waiting for the script to run, log into the newly created server.
Since we changed the port SSH runs on, we have to specify `-p 2222`:

``` bash
ssh -i ~/.ssh/hdm -p 2222 holu@167.233.84.111
```

Note that a login as user `root` is no longer possible, logging in has to be done as the user `holu`.

<img src="img/3.%20Connecting%20to%20the%20server.png" style="max-height: 15lh">

Logging in was successful, confirming the _cloud-init_ configuration was loaded.
No SSH key was provided manually, therefore the _cloud-init_ must have caused the key to be placed into the server's `authorized_keys` file. 

## Checking the setup

The configuration was supposed to set up a simple firewall, allowing only incoming SSH traffic to establish a connection.
In addition, _fail2ban_ should have been set up.
