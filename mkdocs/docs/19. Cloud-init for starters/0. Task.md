## Hetzner - Basic Cloud Config

Summary of [Hetzner's Cloud-init introduction](https://community.hetzner.com/tutorials/basic-cloud-config/).

### Step 1 - Insert first line

The cloud-init config uses YAML ("YAML Ain't Markup Language") as markup language.
The file must start with a comment on the first line so that the code is interpreted as cloud-config by the server:

``` yaml
#cloud config
```

### Step 2 - Create user

After the initial comment, let us start by creating a new admin user with sudo privileges and pre-configured SSH key.

### Step 3 - Update packages

The first thing we do is an update of the package lists and installed packages. 
A fresh copy of Linux may have outdated packages with critical security vulnerabilities.
In this step, you could install necessary packages for your projects too.

### Step 4 – Harden SSH

We need to create a new file in sshd_config.d. 
Settings in /etc/ssh/sshd_config are automatically overwritten by any *.conf file within the sshd_config.d directory.
- Deactivate the root login
- Enable user for SSH
- Change the default port for SSH
- Deactivate password authentication
- Automatic disconnection in case of incorrect login
- Deactivate unused functions

### Step 5 – Run commands

#### Step 5.1 - Configure fail2ban

To secure the SSH network protocol, use fail2ban against brute force attacks

#### Step 5.2 – Enable ufw

Make sure you allow the respective SSH port.

### Step 6 – Create the server

Open the Hetzner Console, select your project and create a server. 
In the "Cloud config" text box, enter the configuration you just created.
