# Course work for 113475 Software Defined Infrastructure

This documentation is meant to supplement the submitted code for the [Software defined Infrastructure lecture exercises](https://medieninformatik.cloud/sdi__listOfExercises__.html).

## Exercise solutions
All solutions are documented and can be navigated to via the sidebar to the left.
There is a page for each exercise, containing entries which detail the exercise description, document the implemented solution, and a verification of the intended results.

Before viewing the solutions, it is advisable to read through the <a href="0.%20Preliminaries">0. Preliminaries</a> section.
It details some information about used commands, the environment the solutions were implemented in, etc. 

The documentation has been written as documentation of results, but in a manner that can be followed along to reproduce said results.
If exercises build on each other, previous solution approaches are presumed to be known and won't be rehashed in detail for each individual documentation.

## Prerequisites
To follow the solutions provided, please ensure the following prerequisites are met:

- [Generating SSH Key-Pair](https://docs.github.com/en/authentication/connecting-to-github-with-ssh/generating-a-new-ssh-key-and-adding-it-to-the-ssh-agent)
- [Install Terraform](https://developer.hashicorp.com/terraform/tutorials/aws-get-started/install-cli)
- [Hetzner Signup](https://accounts.hetzner.com/signUp)
  - [Generating an API Token](https://docs.hetzner.com/cloud/api/getting-started/generating-api-token/)
