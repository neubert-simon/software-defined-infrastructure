## Enhancing index.html generation

We extend our exercise [Cloud-init by Terraform](https://medieninformatik.cloud/sdi_cloudProvider_cloudInit.html#sdi_cloudProvider_qandaCloudInitHetznerByTerra):
- We recently cheated by creating an invalid [HTML](https://medieninformatik.cloud/glossary.html#glo_HTML) file:

```bash
echo "I'm Nginx @ $(curl -4 https://ifconfig.me) created $(date -u)" > /var/www/html/index.html
```

This time start from a proper _tpl/index.html_ template file:

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Template demo</title>
  </head>
  <body>                                     <!-- To become e.g. Sunday 08 Nov 2026 at 18:08 --->
    <h1>Terraform template file demo created ${creationDate}.</h1> 
    <p>This is server <b>${serverName}</b> having IP addresses:</p>
     <ul>
       <li>IPV4: <a href="http://${ipv4Address}">${ipv4Address}</a></li>          <!-- To become e.g. 2a01:4f8:c016:9b2::/64 -->
       <li>IPV6: <a href="http://[${ipv6Address}]">${ipv6Address}</a> from subnet ${ipv6Subnet}</li>
     </ul>
  </body>
</html>
```

- Use Terraform's `templatefile(...)` function to replace all five variables by their respective values using Terraform for generating a gen/index.html file.
- Use Cloud-init to transfer the generated index.html file to its respective location on your destination server. Nginx should then be happily picking it up.
