## A module for ssh host key handling

> Create a `SshKnownHosts` module for generating ssh and scp wrapper scripts among with known_hosts as in [Solving the ~/.ssh/known_hosts quirk](https://medieninformatik.cloud/sdi_cloudProvider_cloudInit.html#sdi_cloudProvider_cloudInit_qanda_solveSshKnownHosts). 

This time refactor ssh, scp and known_hosts generation into a Modules/SshKnownHosts module to be used as:

```terraform
...
resource "hcloud_server" "mySrv" {
name         = "hello"
...
}
```

```terraform
module "createSshKnownHosts" {
source = "../Modules/SshKnownHosts"
loginUserName        = hcloud_ssh_key.loginUser.name
serverNameOrIp       = hcloud_server.mySrv.ipv4_address
serverHostPublicKey  = tls_private_key.host.public_key_openssh
}
```

Your overall project layout may look like:
```
.
├── KnownHostsByModule
│   ├── bin
│   │   ├── scp ━━┓
│   │   └── ssh━┓ ┃ depend

│   ├── main.tf
│   ├── network.tf
│   ├── outputs.tf

└── SshKnownHosts
├── main.tf
├── tpl
│   ├── scp.sh

```

As in [Solving the ~/.ssh/known_hosts quirk](https://medieninformatik.cloud/sdi_cloudProvider_cloudInit.html#sdi_cloudProvider_cloudInit_qanda_solveSshKnownHosts) both ssh and scp use the generated known_hosts file containing the server's public key.
