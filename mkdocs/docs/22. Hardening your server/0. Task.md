## Hardening your server

Extending the previous exercise we address login and firewall related issues.

1. Define a [hcloud_firewall](https://registry.terraform.io/providers/hetznercloud/hcloud/latest/docs/resources/firewall) in favor of a server local [ufw](https://wiki.ubuntu.com/UFW) allowing only [ssh](https://medieninformatik.cloud/glossary.html#glo_ssh) access.
You should not be able to access your server using _http://\<serverIP\>_

2. Add port 80 to the list of allowed incoming connections. Your server should become accessible.

3. With respect to [Figure 1113, “Watch out for your enemies!”](https://medieninformatik.cloud/sdi_cloudProvider_cloudInit.html#sdi_cloudProvider_cloudInit_watchOutForBadGuys) inspect the output of journalctl -f on your server for a while. Can you spot suspicious login attempts?

Read the [sshd_config(5)](https://linux.die.net/man/5/sshd_config) - Linux man page. Then provide a configuration file /etc/ssh/sshd_config.d/99Local.conf by using Cloud-init again. Use this file for overriding suitable ssh server defaults:

- Create a user devops eligible for both ssh login and sudo execution.

    Then restrict ssh logins to the devops user account thereby excluding all other users.

- Disallow ssh password authentication altogether

On success the following sequence should be possible:
```bash
$ ssh -v devops@95.217.154.104
...
debug1: SSH2_MSG_SERVICE_ACCEPT received
debug1: Authentications that can continue: publickey ❶
debug1: Next authentication method: publickey
...
Last login: Sun May  5 19:21:12 2024 from 217.245.243.187

devops@hello:~$ sudo su - ❷
root@hello:~# hostname
hello
```

- password is not among the list of allowed authentication methods.

- User devops may execute sudo commands by virtue of his membership in the sudo group .

On contrary without owning an authorized private key ssh root or devops logins must be prohibited:
```bash
$ ssh root@95.217.154.104
root@95.217.154.104: Permission denied (publickey).

$ ssh devops@95.217.154.104
devops@95.217.154.104: Permission denied (publickey).
```
