    Solution

    Modules

    SSH

    Templates

    Copy the cloud-init template used in Ex. 23 - Solving the known host quirk into Modules/SSH/templates/ssh.yaml. It contains the basic template that can be used to disable root login, pass authorized keys to the server, and pass the host key-pair generated for the SSH wrapper scripts generated via Modules/SshKnownHosts:

    Variables

    Define a variable for the module directory:

    variable "moduleDir" {
  description = "Absolute path to the module directory"
  type        = string
}

    It will be used to select the target directory for the generated cloud-init configuration.

    main.tf

    Load the Conf module:

    module "config" { source = "../Conf" }

    Create the key-pair for the server:

    resource "tls_private_key" "host" { algorithm = "ED25519" }

    Create the cloud-init file with the provided variables for interpolation. Use the template inside the SSH module by employing path.module. Save the generated file to the gen directory inside the exercise directory by using the provided var.moduleDir:

    resource "local_file" "ssh_config" {
  filename = "${var.moduleDir}/gen/ssh.yaml"
  content = templatefile("${path.module}/templates/ssh.yaml", {
    host_ed25519_private = tls_private_key.host.private_key_openssh
    host_ed25519_public  = tls_private_key.host.public_key_openssh
    devopsUsername       = module.config.loginUserName
    ssh_authorized_keys  = module.config.authorizedKeys
  })
  depends_on = [tls_private_key.host]
}

    SshKnownHosts

    Templates

    Copy the script templates used in Ex. 23 - Solving the known_hosts quirk into SshKnownHosts/templates.

    For the SSH script, replace devops with the template variable `user:

    #!/bin/bash
ssh -i "${pk}" -o "UserKnownHostsFile=\"${genDir}/known_hosts\"" ${user}@${ip} "$@"

    #!/bin/bash
if [ $# -lt 2 ]; then
   echo "usage: .../bin/scp ... devops@${ip} ..."
else
   scp -i "${pk}" -o "UserKnownHostsFile=\"${genDir}/known_hosts\"" "$@"
fi

    Variables

    Define all variables for the information that needs to be accessible inside the child module.

    Define a variable to store the server id to be able to access the server information:

    variable "server" {
  description = "Server id"
  type        = string
}

    Define a variable for the Unix user:

    variable "user" {
  description = "User to log in as on the server"
  type        = string
}

    Define a variable for the private key file you wish to use to be able to log into the machine with:

    variable "user_private_key" {
  description = "Private key file to authenticate via ssh with"
  type        = string
  sensitive   = true
  nullable    = true
}

    Define a variable for the public key the machine will be using:

    variable "host_public_key" {
  description = "Public key used by the host system"
  type        = string
}

    Define a variable for the absolute path of the module directory:

    variable "moduleDir" {
  description = "Absolute path to the module directory"
  type        = string
}

    Define a variable for your bin directory (a directory on your $PATH):

    variable "bin" {
  description = "Filepath to bin directory on $PATH"
  type        = string
}

    main.tf

    Define the data block for the server, as was done in Ex. 24 - Generating host metadata

    data "hcloud_server" "server" {
  id = var.server
}

    known_hosts

    Create the known_hosts file via the local_file resource. Pass the IPv4 address assigned to your server and the public key you assigned it to use:

    resource "local_file" "known_hosts" {
  content = join(" ",
    [data.hcloud_server.server.ipv4_address, var.host_public_key]
  )
  filename        = "${path.module}/gen/known_hosts"
  file_permission = "644"
}

    SSH wrapper

    Now define the SSH wrapper. Use the template in the module's templates directory by employing ${path.module}. Pass the necessary information for string interpolation:

    resource "local_file" "ssh_script" {
  content = templatefile("${path.module}/templates/ssh.sh", {
    ip    = data.hcloud_server.server.ipv4_address
    user  = var.user
    pk    = var.user_private_key
    exDir = var.moduleDir
  })
  filename        = "${var.bin}/ssh${data.hcloud_server.server.name}"
  file_permission = "755"
  depends_on = [local_file.known_hosts]
}

    SCP wrapper

    Define the SCP wrapper in the same manner:

    resource "local_file" "scp_script" {
  content = templatefile("${path.module}/templates/scp.sh", {
    ip     = data.hcloud_server.server.ipv4_address
    pk     = var.user_private_key
    genDir = "${abspath(path.module)}/gen"
  })
  filename        = "${var.bin}/scp${data.hcloud_server.server.name}"
  file_permission = "755"
  depends_on = [local_file.known_hosts]
}

    Parent Module

    Create the server with a generated key-pair and the required SSH config via cloud-init:

    # Set up the default server
resource "hcloud_server" "g01" {
  name        = module.server.serverName_g01
  image       = module.server.serverImage
  server_type = module.server.serverType
  location    = module.server.serverLocation

  firewall_ids = [module.firewall.firewallID]
  ssh_keys = module.hetzner.authorizedKeys

  user_data = module.ssh.ssh_config
  depends_on = [module.server, module.hetzner, module.ssh, module.firewall]
}

    Then import the SshKnownHosts module and pass the necessary variables to create the wrapper scripts:

    module "ssh_wrapper" {
  source = "../Modules/SshKnownHosts"
  moduleDir = abspath(path.module)
  bin    = module.config.bin

  user             = module.config.loginUserName
  user_private_key = module.config.pk

  host_public_key = module.ssh.host_public_key
  server          = hcloud_server.g01.id

  depends_on = [hcloud_server.g01]
}
