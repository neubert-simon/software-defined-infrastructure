    Solution

    Firewall

    Supplying a firewall that only allows SSH traffic can be achieved by supplying only the rule name ssh to the Firewall module:

    module "firewall" {
  source = "../Modules/Firewall"
  rules = ["ssh"]
}

    To allow web traffic, add "http" to the list of rule names: rules = ["ssh", "http"]

    Upgrading the server automatically

    To upgrade the distribution at server creation time, the following directives can be added to the cloud-init configuration:

    package_reboot_if_required: true
package_update: true
package_upgrade: true

    The package_reboot_if_required directive ensures that the system reboots if necessary to complete the operation.

    Installing and running services

    The exercise calls for three services, nginx, fail2ban, and plocate. To install them, add their respective name to the packages directive, and enable it with systemctl under the run-cmd directive:

    packages:
  - nginx
  - fail2ban
  - plocate

runcmd:
  - systemctl enable fail2ban
  - systemctl enable nginx
  - systemctl enable plocate
  - sudo updatedb

    Plocate

    plocate additionally requires sudo updatedb to initialize the index-based locate command. To learn more, visit:

    Devops user

    To set up the user devops, cloud-init was employed. Add the following line to assign sudo rights to the user devops:

    sudo: ALL=(ALL) NOPASSWD:ALL

    The complete user configuration should look like this:

    users:
  - name: devops
    groups: users, admin
    sudo: ALL=(ALL) NOPASSWD:ALL
    shell: /bin/bash
    ssh_authorized_keys:
      - YOUR PUBLIC KEYS HERE

    Dynamic user creation will be done in the next exercise, see Ex. 23 - Solving the known_hosts quirk

    SSH

    SSHD Configuration

    To alter the default ssh daemon configuration, cloud-init was employed to write a configuration file to /etc/ssh/sshd_config.d/. Both root login and authentication via password were disabled via PermitRootLogin no and PasswordAuthentication no respectively.

    write_files:
  - path: /etc/ssh/sshd_config.d/99Local.conf
    content: |
      PermitRootLogin no
      PasswordAuthentication no
      AllowUsers devops

    To learn more, visit:

    • sshd_config(5) - Linux man page
